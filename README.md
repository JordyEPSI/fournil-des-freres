# :french_bread: Projet de Stage : Site Vitrine - Fournil des Frères

## :pencil: Présentation du projet
Ce projet est réalisé dans le cadre de mon **stage de 1ère année à l'EPSI**. 
L'objectif est de concevoir et déployer le site vitrine officiel de la boulangerie-pâtisserie **"Fournil des Frères"**, située au 2596 Avenue de l'Europe à Montpellier.

L'établissement possède une forte réputation locale (4.6/5 sur Google) et ce site vise à moderniser leur image numérique, afficher leurs produits phares et optimiser leur référencement local.

## :rocket: Objectifs Pédagogiques Validés
Conformément à ma convention de stage, ce projet permet de valider les compétences suivantes :
- **Développement Front-end** : Utilisation des langages de base du web (HTML5, CSS3, JavaScript).
- **Gestion de Projet & Git** : Utilisation du versioning avec Git et déploiement via GitHub Pages.
- **UI/UX Design** : Conception d'une interface ergonomique respectant l'identité visuelle de la boulangerie (Palette Noir & Or).
- **SEO Local** : Optimisation du référencement pour améliorer la visibilité sur Google Maps et les recherches locales à Montpellier.

## :tools: Technologies Utilisées
- **Architecture** : Site statique optimisé pour la performance.
- **Hébergement** : GitHub Pages (Solution professionnelle et sécurisée).
- **Design** : CSS3 personnalisé (Flexbox/Grid) pour un rendu "Mobile First".
- **Outils tiers** : 
  - Google Maps API (Intégration de l'emplacement).
  - Formspree (Gestion du formulaire de contact sans back-end).
  - IA Générative (Aide à la rédaction des contenus et optimisation des visuels).

## :art: Identité Visuelle
Le site reprend les codes du logo artisanal :
- **Primaire** : `#C5A059` (Or Moisson)
- **Secondaire** : `#1A1A1B` (Charbon Sombre)
- **Typographie** : Élégante et lisible pour refléter l'aspect premium des pâtisseries.

## :open_file_folder: Structure du dépôt
- `/index.html` : Page d'accueil et structure principale.
- `/css/` : Feuilles de style personnalisées.
- `/img/` : Galerie de photos des produits et logo.
- `/js/` : Scripts pour les animations et interactions.
